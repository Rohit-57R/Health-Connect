# 🏥 HealthConnect – Healthcare Support Portal

A modern, responsive, and interactive **Healthcare Support Web Application** built using HTML, CSS, and JavaScript.

---

## ✨ Features

- 🧑‍⚕️ Patient Registration System  
- 🧠 AI Health Summary Generator  
- 🏥 Smart Department Recommendation  
- 🤖 Healthcare FAQ Chatbot  
- 🙋 Volunteer Registration System  
- 💡 Daily Health Tips Generator  
- 🚨 Emergency Helpline Section  
- 📊 Patient History (Local Storage)  
- 🌙 Dark Mode Support  
- 🎨 Smooth Animations & Responsive UI  

---

## 📂 Project Structure

HealthConnect/
│
│── index.html      → Main UI structure
│── style.css       → Styling & animations
│── script.js       → All functionality
│── README.md       → Project documentation

## ▶️ How to Run

- Download or clone the repository  
- Open the project folder  
- Double-click on `index.html`  
- Start using the app in your browser  

---

## 🎮 How It Works

- Enter patient details in the registration form  
- Describe health issue  
- System generates AI-style health summary  
- Get recommended medical department  
- Use chatbot for quick answers  
- Register as volunteer (optional)  
- View stored patient history  
- Toggle dark/light mode for better UI experience
